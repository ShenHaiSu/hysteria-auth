## 重难点

| 难点 | 说明 | 解决方案 |
|------|------|----------|
| **ECharts 暗色主题适配** | 亮/暗色切换时图表需同步更新配色 | `BaseChart.vue` 通过 `theme` prop 接收当前模式，切换时 `dispose()` + 重新 `init()` |
| **图表 Resize 响应** | 侧边栏折叠/窗口大小变化时图表需重新计算尺寸 | `useECharts` 中监听 `window.resize`，`BaseChart` 中暴露 `resize()` 方法 |
| **双 Y 轴图表的刻度对齐** | 网络速率的上行/下行可能数量级不同 | 使用 ECharts 的 `yAxisIndex` 分别配置两个 Y 轴，`min`/`max` 自动计算 |
| **大数据量图表的性能** | 节点状态历史可能返回大量数据点 | 使用 ECharts 的 `dataZoom` 组件支持缩放，`sampling: 'lttb'` 降采样 |
| **Excel 导入的数据校验** | 批量导入前需校验每行数据合法性 | 先解析 → 逐行校验 → 展示预览表格（标注校验失败行）→ 用户确认后批量提交 |
| **导入大量用户时的超时** | 逐个创建数百用户可能耗时较长 | 使用并发池（如 `p-limit` 控制同时 5 个请求），显示进度条 |

---

## 注意点

1. **ECharts 按需引入**：只注册实际使用的图表类型和组件，减小打包体积
2. **图表初始化时机**：确保 DOM 已挂载（`onMounted`），容器尺寸不为 0
3. **图表实例清理**：`onBeforeUnmount` 中必须 `dispose()`，避免内存泄漏
4. **导出文件名**：包含导出日期，如 `用户列表_2026-05-22.xlsx`
5. **导入模板**：提供标准 `.xlsx` 模板下载，包含列头和示例数据
6. **导出数据量限制**：单次导出建议不超过 10000 条，超限时提示用户缩小筛选范围
